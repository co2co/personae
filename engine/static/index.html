采样参数 SAMPLING ▾

以下参数与具体模型无关，全局统一控制 LLM 采样行为；无论使用本地还是在线模型均生效。

温度 top_p min_p
top_k max_tokens
重复度惩罚 0.30
min_p 动态截断：只保留「概率 ≥ min_p × 最高概率」的候选，比固定 top_p 更抗长输出走神（正文退化、同一段剧情被整段重写）。填 0 则不启用。重复度惩罚：拖高可抑制复读（同一句话/同一段剧情反复出现），0 = 不惩罚，0.3 为保守推荐值；过高会让用词僵硬甚至输出中断，一般不超过 1.0。引擎会自动适配不同后端。
一键回填出厂默认值（仅改输入框，点「保存」生效）。

打开世界书使用说明（新窗口）

剧本库

一个剧本 = 一本世界书 + 该剧本全部角色。左栏选剧本，右栏管理它的「世界书设定」与「角色表」。
剧本
还没有任何剧本。点左上「+ 新剧本」创建一个（剧本名即世界书名）， 或用「从剧本生成」把剧本一键提炼成角色与设定。
两类条目：设定（默认，触发词命中场景/对话才注入 prompt）； 秘密（勾选后不注入 prompt，仅在开局 seed 进该角色的秘密表，按曝光逻辑推进）。 顺序自上而下即注入优先级（顶部最高），拖 ⠿ 调整。保存即整份覆盖写入 data/worlds/<剧本名>.json。
带 * 为必填项，不填推演引擎无法完整发挥；其余为可选，留空由系统自动生成。
角色必须归属于某个已存在的剧本（世界书）；下拉选择、不可手填，避免错写 world 导致开局加载错世界。默认即当前剧本，导入 JSON 后可改派归属。
更多字段（可选；留空由系统自动生成）
