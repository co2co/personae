创建剧本指南 · 群像弈

创建剧本指南（引擎机制与题材适配）

适用版本：群像弈（Personae）【暂定】。本文档面向想写自己的剧本、但还没动笔的创作者：先讲清楚这套引擎靠什么机制运转，再据此说清它适合什么题材、不适合什么题材，最后用一份随包的官方示例剧本拆给你看——一份好剧本到底该给引擎喂什么。

它和另外两份文档的分工：世界书使用说明讲「设定条目怎么配」，剧本范例指南讲「文本怎么写才让提炼器识别」。本篇讲更上一层的选题与结构——动笔之前先读这份，少走弯路。

一、先说清这引擎到底给你什么体验

群像弈是一个多角色关系沙盘。你和普通「AI 角色扮演」最大的区别在角色定位：

  • 你不是其中任何一个角色。你是外部导演——不登场、不说话、不指挥谁做什么，只往这个世界里注入扰动（一句环境指令、一个突发状况、一句旁白）。
  • 真正在演的是一群各有动机、互相看不顺眼或互相纠缠的角色。他们会按自己的欲望、恐惧和秘密各自行动，关系会随事件演化，秘密会在某一刻被揭开。
  • 你的乐趣不在「我变强 / 我赢了」，而在看这个迷你世界如何自己运转、崩盘、翻盘——谁背叛了谁、哪条暗线爆了、资源够不够分。

一句话：它是「看群像互相博弈」的推演器，不是「我当主角一路变强」的成长器。想清楚这一点，下面的「适合 / 不适合」就顺了。

二、引擎靠什么机制运转（你该喂它什么的前提）

引擎有五个核心机制。理解它们，你就知道一份剧本该提供哪些料。

1. 关系簿记 —— 关系是活的，会演化

每个角色卡上都写着他和在场每个人的关系（谁是他的靠山、谁是他要防的人、谁他有好感却不敢说）。开局这些关系被冻结成基准，之后随事件一步步变：一次背叛能让同盟翻脸，一次共同担惊能让仇敌暂时抱团。引擎的甜区就在这里——「人和人之间的暗线」是它最擅长演的。

2. 秘密簿记 —— 暗线逐步揭开

每个角色可以藏一桩见不得光的旧事。它开局是「潜伏」的（模型并不主动知道），只有当剧情里真的写出「发现动作 + 秘密事实」（比如有人拆开了那层隐瞒），引擎才把它翻成「暴露」，并把知情者记下——从此知情者可以拿它要挟、可以保护性隐瞒、关系随之改写。秘密不进提示词，它的「爆」是演出来的，不是设定出来的。

3. 世界书 —— 背景设定按需注入

世界观、地点、规则、威胁等背景，写成一条条世界书条目。分两种命：

  • 常量条目：每轮恒在场，是「铁背景」（世界观法则、当前处境总则）。
  • 触发条目：只有相关关键词被提到才注入（某个地点、某条规则、某个当下威胁）。

条目的位置（before/after）与扫描深度（depth）决定它怎么影响模型——这部分细节请读世界书使用说明，本篇不展开。

4. 导演指令 —— 你唯一的介入方式

你每轮注入的「环境扰动」是推演世界的唯一外力。写得越具体（一个可感知的状况、一句能引发不同角色不同反应的旁白），群像的分支就越丰富。写「天下大乱」会摊平，写「门外传来第三声撬动、补给只剩最后半天」才会让每个人各自算各自的账。

5. 设计红线 —— 引擎被刻意设计成「不给主角光环」

这是理解题材适配最关键的一条。引擎在设计上就刻意：

  • 无主角：没有谁被预设成「观众跟的那一个」，群像里人人都有自己的动机。
  • 缠斗最大化：鼓励多方牵制、互相拆台，而不是「目标明确、一路推进」。
  • 爽点落小事：爽的是「一个秘密被拆穿」「一次背叛被反将」「资源不够分时谁先让步」，不是「境界突破」「实力碾压」。
  • 终局悬置：引擎不追求给你一个干净利落的「大团圆 / 大结局」，世界停在某个张力最高的悬置点。

把这五条合起来看：引擎的爽感引擎 = 关系与秘密的博弈，而不是「个人成长曲线」。它擅长把「人和人之间的暗线」演出来，不擅长把「一个人变强」演出来。

三、它最适合什么样的剧本

特征为什么适合
长时同域群像（一群人在同一个封闭/半封闭空间或圈子里长期共处：一船、一栋楼、一间诊所、一个宗门内门、一个小村、一个科室）群像共处 = 关系网 + 秘密簿记的用武之地，是引擎的绝对甜区
强关系网 + 隐藏秘密（师徒/同门/道侣/仇敌/把柄/身份伪装/组织黑历史）关系会演化、秘密会逐步揭开，这两条是引擎的核心机制，喂得越多越出彩
资源 / 利益冲突驱动的缠斗（物资、配给、道统、话语权、地盘、一份名额、一笔账）「有限资源怎么分」天然制造多方牵制与让步/背叛，正中「缠斗最大化」
多方势力 + 不稳定同盟 + 背叛（三足鼎立、合纵连横、今日盟友明日对手）不稳定同盟是引擎被刻意设计的玩法，越不稳定越好演
悬疑 / 真相揭开型（一桩旧案的真相、一个功法/血脉/秘境的来历、一个组织掩埋的丑闻）「谁在瞒、瞒了什么、何时被谁拆穿」= 秘密簿记 + 关系簿记的完美载体

判据一句话：你的故事里，「人和人之间的暗线 / 张力 / 把柄」是不是主要驱动力？是，引擎就很适合。

四、它对什么样的剧本兼容度差

不是「这些题材不能写」，而是这些题材的核心爽点恰好落在引擎不擅长 / 被刻意回避的机制上，硬做会「水土不服」。逐条说清为什么不匹配：

题材类型核心爽点在哪为什么与引擎机制错位
升级 / 养成 / 金手指流（含修仙玄幻的「境界突破、废柴逆袭、打脸」） 「我变强了」「越级反杀」「境界突破」 引擎没有数值 / 进度簿记——不追踪「你现在几级 / 突破没突破」，靠世界书 + 模型软性维持，长轮次会漂移；且设计红线「爽点落小事、终局悬置」与「一路变强的成长爽感」方向相反。硬做升级流，成长线会散、突破时机会失真。
强规则 / 强数值战斗（战棋、卡牌、技能 combo、策略对抗） 「这招配那招」「数值算下来能赢」 引擎不做数值战斗判定，战斗只能作为叙事事件被模型软性描述，无法支撑「靠规则取胜」的玩法。
黑箱系统题材（商战、金融投资、律政、政治博弈的内在逻辑） 「算准了行情 / 抓住了规则漏洞」 这类题材的推理建立在外人看不透的专业规则黑箱上。玩家没法像「水够撑三天」那样去推理，引擎的推演也依赖模型对黑箱的软性理解，容易失真。选题材宜贴近普通人常识（水、粮、武器、医药、名额）。
单一主角强叙事推动（个人英雄、一条复仇主线、闯关式推进） 「跟着主角一步步推进到终点」 引擎无主角、终局悬置。把全部笔墨押在一个主角的主线上，群像的「互相博弈」会被压扁，引擎最值钱的关系/秘密机制用不上。

特别说修仙：修仙题材本身能做，但要做成「宗门群像 / 权谋」而不是「升级爽文」——把修为当背景板（用常量条目定境界与战斗规则，不让玩家推数值），把主角位让给宗门内斗、道统之争、功法黑历史、师徒道侣仇敌这些关系与秘密。想要「我修炼逆天改命」的成长爽感，引擎给不了。

五、一份好剧本该给引擎喂什么

对照上面的机制，一份能跑出好戏的剧本，至少该提供下面这些「料」：

A. 角色卡（每个角色都要齐）

引擎靠角色卡上这几个字段驱动行为，缺哪个角色就会「木」：

字段给什么缺了会怎样
description性别 / 年龄 / 定位，一句话身份角色失去基本轮廓
personality正面特点 + 缺点 / 软肋（让角色会犯错的关键）角色「永远理性」，没有暗线可挖
core_desire他最想要什么——驱动行为的引擎角色没有动机，剧情推不动
core_fear他最怕什么——越线的底线角色没有「不能碰的东西」，张力消失
relations和在场每个人各自的关系（靠山 / 提防 / 好感 / 仇视）群像塌成几个孤岛，关系网演化不起来
secret（写进世界书秘密条目）一桩见不得光的旧事（已发生、可被逼近、可被揭穿）少一条暗线，「秘密逐步揭开」的爽点少一截

关键比例：欲望（想要）+ 恐惧（最怕）+ 关系（对谁什么态度）三者齐了，角色才「会自己动」。秘密是加在群像上的「雷」，埋得越多，后面爆得越响。但秘密要写「已发生的旧事」，不是「性格特点」——旧事才能被一步步逼近、最终揭穿。

B. 世界书（背景与处境）

  • 常量打底：把「铁背景」勾成常量——世界观法则、当前处境总则（谁被困在哪、有什么禁忌、资源多紧）。这是防「聊远了设定就蒸发」的地基。
  • 触发补充：地点、规则、当下威胁等随剧情命中再补，别全塞常量（会挤占注入配额，每条被稀释）。
  • 资源 / 压力要写具体：「补给见底、只剩最后半天」比「物资紧张」更能逼出每个人各自算账。

C. 结构上该做的三件事

  1. 给多方，不给单一主角：至少 3 方有互相冲突的诉求（不是「一个目标一起冲」）。诉求冲突 + 资源有限 = 自动缠斗。
  2. 埋一条不稳定同盟：让两方暂时抱团、但各怀鬼胎——这是「合纵连横 / 背叛」爽点的种子。
  3. 埋 2–3 条可被揭穿的秘密：分散在不同角色身上，彼此最好能互相牵制（A 的秘密恰好是 B 的把柄），暗线才会缠成网。

六、以官方示例剧本《困守一栋楼》为例拆解

引擎随包带了一份示例剧本（在「从剧本生成设定」面板可打开 data/examples/script-example.txt 看全文）：四个人被困在一座断电公寓里。下面不抄原文，只拆「它为什么是一份适合引擎的剧本」——逐条对应第五节的清单。

为什么它「适合」——对照机制逐条看

它做了什么命中了哪个机制 / 清单项
四个人困在同一栋楼、一天到晚挤在一起避不开长时同域群像（甜区）+ 空间逼仄放大人际摩擦
四个角色诉求互相冲突：要护全楼的人 / 想救人却可能害死全队 / 想护住孩子 / 想找回父亲多方冲突诉求（结构·第 1 件）——没有单一主角，人人自顾
资源有限：存粮药品见底、按天配给、谁出工谁多领资源压力驱动的缠斗 + 「该给谁多分」的天然冲突点
队长拿母子的生死做筹码——一个不稳定同盟 + 各怀鬼胎不稳定同盟（结构·第 2 件）——合纵连横的种子
每人一桩见不得光的旧事（谁害了旧队 / 谁在等谁死尽 / 谁在拿身体换庇护 / 谁不敢坐实最坏答案），且彼此能牵制秘密簿记 + 秘密互相牵制（结构·第 3 件）——暗线缠成网
「感染临界」写成人推得出的处境（伤口变化、要不要瞒、在哪处理），而非黑箱数值贴近常识、可推理——玩家和引擎都能据理推演，不靠黑箱
世界书：病毒法则 / 配给规矩是常量；公寓 / 楼道 / 地库 / 逼近的威胁是触发情境常量打底 + 触发补充，分层清晰不挤配额

反例：同一份剧本如果「喂错了」会怎样

  • 若把「四人一起冲出去求生」当唯一主线（单一主角强叙事）→ 关系网被压扁，退化成普通冒险文，引擎最值钱的关系/秘密机制用不上。
  • 若给队长一条「境界突破、越级反杀尸潮」的成长线（升级流）→ 引擎不追踪境界，突破时机会漂移、爽感落不了地。
  • 若把秘密写成「他其实很温柔」（性格特点）而非「他等旧队死尽才动手」（已发生旧事）→ 没有可被逼近揭穿的把柄，秘密簿记失效。

《困守一栋楼》好在哪，一句话说尽：它把笔墨全押在「四个自顾的人，困在一起、资源不够分、各揣一桩旧事」上——关系、秘密、资源、不稳定同盟，引擎的四个甜区它全喂到了。

七、常见误区

  1. 以为引擎能带主角升级：它无主角、无进度簿记、终局悬置。想要成长爽感请换赛道；想做群像博弈它才上道。
  2. 把黑箱题材直接搬进来：商战 / 金融 / 律政的内在规则外人推不出来，引擎也推不稳。选「贴近常识」的冲突（水、粮、武器、医药、名额）。
  3. 角色只写性格不写欲望 / 恐惧 / 关系：缺了动机和关系网，角色不会自己动，群像变孤岛。
  4. 秘密写成「性格特点」：要写「已发生、见不得光、可被揭穿」的旧事，才有得爆。
  5. 只给一个共同目标：「大家合力干成一件事」= 没有缠斗。要「各方诉求互相冲突 + 资源有限」。
  6. 背景全塞常量：常量太多挤占注入配额、每条被稀释。铁背景才常量，地点 / 规则 / 威胁走触发。
  7. 导演指令写得太抽象：「天下大乱」摊平分支；「门外第三声撬动、补给只剩半天」才逼出每个人各自的算计。

八、动笔前自检清单

问自己通过标准
主角位让出去了吗？有 3 方以上互相冲突的诉求，没有预设「跟的那一个」
资源 / 利益够紧吗？存在「有限、怎么分、谁先让步」的具体压力点
关系网连起来了吗？每个角色都写了对在场每人的态度，且能随事件演化
秘密埋够了吗？2–3 桩「已发生的旧事」，且彼此能牵制
有不稳定同盟吗？至少两方暂时抱团但各怀鬼胎
冲突贴近常识吗？玩家能像推理「水够三天」那样推理，不靠黑箱规则
背景分层了吗？铁背景常量打底，地点 / 规则 / 威胁走触发，没全塞常量

想真正上手，建议两步：① 打开「从剧本生成设定」，把随包的 script-example.txt 整段粘进去，看引擎怎么把它提炼成角色卡 + 世界书；② 对照本篇第五 / 六节，把它的结构替换成你自己的设定。写完之后，用「命中预览」验证世界书触发词、用开局跑两三轮验证群像动没动起来。
